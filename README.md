# 🎵 VibeUp
> 음악으로 연결되는 새로운 소셜 네트워크 서비스  

VibeUp은 사용자들이 직접 올린 음악과 플레이리스트를 공유하고, 포스트를 통해 감정을 표현하며, 좋아요와 댓글로 교류할 수 있는 **음악 기반 SNS 플랫폼**입니다.  

---

## 📌 주요 기능 (Features)
- 👤 **회원 관리**: 회원가입, 로그인, 팔로우/팔로잉  
- 📝 **포스트 업로드**: 음악과 함께 글/감정을 공유  
- 💬 **댓글 & 좋아요**: 자유로운 소통 기능  
- 🎶 **플레이리스트**: 나만의 플레이리스트를 생성/공유  
- 🔒 **공개 범위 설정**: Public / Private 선택 가능  

---

## 🛠️ 기술 스택 (Tech Stack)
- **Backend**: Spring Boot (Java)  
- **Database**: MySQL (ERD 설계 기반)
